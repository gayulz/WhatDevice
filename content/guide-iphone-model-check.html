내 아이폰 모델 확인하는 법: 모델 번호와 식별자의 차이

확인 기준: Apple 지원 문서, 2026년 11월 10일 확인

설정 > 일반 > 정보에서 모델 번호 칸을 한 번 탭하면 모델 번호가 나옵니다. 처음에는 부품 번호가 보이고, 탭해야 모델 번호로 바뀝니다. 로그에 찍힌 iPhone15,2 같은 식별자는 이 화면에 나오지 않으므로 식별자 검색에서 기종명으로 바꿔 확인하세요.

표기모양어디서 보나무엇을 구분하나
기종명iPhone 14 Pro판매 페이지, 제품 사양판매되는 제품
모델 번호A로 시작하는 번호설정 앱, 기기 본체판매 국가·지역별 모델
식별자iPhone15,2크래시 로그, 애널리틱스, 개발 도구하드웨어 종류

Apple은 같은 기종이라도 판매 국가나 지역에 따라 모델 번호가 다르다고 안내합니다. 그래서 모델 번호는 기종명보다 잘게 나뉩니다. 식별자도 같은 기종에 두 개 이상 붙는 경우가 있습니다. 예를 들어 iPhone 18 Pro Max에는 iPhone19,3과 iPhone19,7이 대응합니다.

설정 앱이 열리지 않을 때: 기기 본체에서 확인

  • iPhone 7 이하: 기기 뒷면에 모델 번호가 인쇄되어 있습니다.
  • SIM 트레이가 있는 iPhone 8 이후: SIM 트레이를 빼고 밝은 곳에서 슬롯 안쪽, 디스플레이 쪽 면을 봅니다.
  • SIM 트레이가 없는 iPhone: USB-C 또는 Lightning 커넥터 위쪽(디스플레이 쪽)을 밝은 곳에서 봅니다.

확인한 모델 번호를 Apple의 iPhone 모델 식별하기 목록과 대조하면 기종명을 알 수 있습니다.

로그에 찍힌 식별자로 기종을 알아야 할 때

개발자나 기술 지원 담당자는 사용자 기기를 직접 볼 수 없고, 로그에 남은 식별자만 받는 경우가 많습니다. 이때는 모델 번호가 아니라 식별자를 기종명으로 바꿔야 합니다. 주의할 점은 식별자의 숫자가 판매명의 숫자와 다르다는 것입니다. iPhone15,2는 iPhone 15가 아니라 iPhone 14 Pro입니다.

식별자를 찾는 위치는 크래시 로그·애널리틱스에서 기기 모델 확인하는 법에, 식별자 형식은 애플 기기 식별자란 무엇인가에 정리했습니다. 전체 목록은 iPhone 식별자 목록에서 볼 수 있습니다.
